# 校园日历

一个不需要后端的校园生活日历：添加课程、学习计划、生活安排和截止日期，并在浏览器本地保存。

## 在线发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `campus-calendar`。
2. 上传本文件夹中的 `index.html`、`style.css` 和 `app.js`。
3. 在仓库的 **Settings → Pages**，选择从 `main` 分支、`/(root)` 目录部署并保存。
4. GitHub 会显示网站链接，通常形式为 `https://你的用户名.github.io/campus-calendar/`。

所有日程当前只保存在访问者自己的浏览器中；发布网站不会上传或共享日程。
